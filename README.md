# FunPay Seller

Панель продавца FunPay со статистикой, текущими заказами, управлением
друзьями Steam и автоподнятием предложений.

Стек: React + Vite (frontend), FastAPI (backend), MongoDB, Docker Compose.

## Запуск

Запустите Docker Desktop на Windows/macOS или Docker Engine с Compose на
Linux. Проверьте, что команда `docker compose version` работает.

Получите доступ к [репозиторию на GitHub](https://github.com/DamirKFU/vladfunpay).
Для запуска без Git скачайте **Code → Download ZIP** и распакуйте архив.
Если Git установлен, можно клонировать исходники:

```bash
git clone https://github.com/DamirKFU/vladfunpay.git
cd vladfunpay
```

Откройте терминал в папке, где лежит `docker-compose.yml`, и выполните:

```bash
docker compose up -d --build
docker compose ps
```

Откройте [панель на localhost:8080](http://localhost:8080). При первом
входе создайте администратора и заполните настройки в браузере. Для
первого запуска достаточно Docker, дополнительные сервисы ставить не нужно.

| Вкладка | Что нужно |
|---|---|
| FunPay | cookie `golden_key` и User-Agent браузера |
| Steam | Web API Key и SteamID64. Для показа ожидающих заявок можно дополнительно указать cookie `steamLoginSecure`. |
| Друзья | Закреплённые друзья и частота обновления списка. |

Для остановки выполните `docker compose down`. Если панель не открылась,
посмотрите состояние контейнеров в `docker compose ps` и журнал в
`docker compose logs --tail=100`.

Ключи хранятся в MongoDB в зашифрованном виде. Ключ шифрования создаётся при
первом запуске в volume `app-data` — не удаляйте этот volume, иначе ключи
придётся ввести заново.

По умолчанию сайт открыт только на этом компьютере. Чтобы открыть его в
локальной сети, создайте `.env` из `.env.example` и поставьте
`APP_BIND=0.0.0.0`.

## Обновление

В клонированном репозитории выполните `git pull --ff-only`, затем
`docker compose up -d --build`. Если проект был скачан ZIP-архивом,
распакуйте свежую версию и выполните ту же команду Docker. Именованные тома
MongoDB и настроек сохраняются при пересборке. Команда
`docker compose down -v` удаляет данные.

## Что умеет

- **Продажи.** Первая синхронизация загружает историю продаж через экспорт
  FunPay. Дальнейшие выгрузки идут с последней оплаты или старейшего
  открытого заказа. Статистика обновляется примерно раз в час. В отчёте
  доступны графики и фильтры. Есть ручное обновление.
- **Заказы.** Все открытые заказы и последние продажи FunPay со статусами
  площадки. Доступны поиск, фильтры, ссылки на заказы и время последнего
  успешного обновления. Автосинхронизация каждые две минуты после завершения
  предыдущего запроса. При ошибке виден последний успешно загруженный список.
- **Друзья Steam.** Просмотр друзей и ожидающих заявок, закрепление и поиск.
  Сверху закреплённые и покупатели с открытым заказом. Остальные идут по
  дате последней покупки и затем по дате добавления. Давние друзья без
  покупок идут в конце списка друзей. Входящие и исходящие заявки идут
  после друзей.
- **Автоподнятие** в «Настройки → FunPay». Категории берутся из продаж
  или задаются вручную. Следующее поднятие назначается по ответу FunPay.
- **Логи и выгрузка базы.** Поиск по журналу, выгрузка логов в JSONL и
  экспорт данных в ZIP. Пароли и ключи исключены из выгрузки.

В приложении заказы доступны для просмотра. Список заказов и автоподнятие
используют библиотеку [funpaybotengine](https://github.com/funpayhub/funpaybotengine).
Статистика использует встроенную выгрузку FunPay.

## Разработка

```bash
cd backend
python -m venv .venv && .venv/Scripts/pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest          # тесты на реализациях в памяти
.venv/Scripts/ruff check app tests

cd ../frontend
npm install && npm run dev               # http://localhost:5173, /api → :8000
```

Тесты репозиториев против настоящей MongoDB:

```bash
docker compose --profile test run --rm backend-tests
```

Бэкенд использует интерфейсы для хранилищ и внешних сервисов. Тесты
используют реализации в памяти и проверяют контракты хранилищ на MongoDB.

Старый CLI для выгрузки и HTML-отчёта лежит в `legacy/`.
